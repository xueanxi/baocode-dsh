This release hands DSH's model over to Settings → Models: every upstream turned on can be switched to inside a conversation, and an older conversation no longer fails because it recorded an upstream that is gone.

New
- Every model of every upstream turned on in Settings → Models is in the DSH conversation's model picker; switching within or across upstreams needs no restart.
- DSH model names the model a conversation starts on; with none picked it starts on the default model, keeping this machine's dsh/dsh.env model where that one is among those turned on.
- Follow DSH's own configuration is still there on its own, going through dsh web or dsh/dsh.env.
- An upstream's key stays in the app; dsh is given only the local proxy's token, made anew each run and never written to a file.

Fixed
- A conversation that recorded an upstream this route no longer declares no longer fails with `no adapter registered for provider "…"`: it opens, then moves onto the current route's model.
- Full access no longer treats a dangerous command's safety check as something to confirm by hand.
